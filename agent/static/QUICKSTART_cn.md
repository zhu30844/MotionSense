# MotionSense Web 界面 - 快速入门指南

[English](QUICKSTART.md) | 简体中文

最后编辑：2026-10-24

几分钟内即可上手使用 MotionSense Web 界面。

## 🚀 快速入门

### 1. 访问界面
打开 Web 浏览器并访问：
```
http://192.168.1.1
```

**注意：** 请将 `192.168.1.1` 替换为您的 MotionSense 设备的实际 IP 地址。

### 2. 主界面概览

Web 界面包含三个主要部分：

#### 📹 实时监控
- **用途**：观看实时视频画面
- **功能**：
  - 实时 MJPEG 视频流
  - 连接状态指示
  - 连接中断时自动重连

#### 📅 日历与热力图
- **用途**：按日期浏览录制的视频
- **功能**：
  - 月历视图
  - 运动强度热力图（红色 = 运动越多）
  - 点击任意日期查看录像

#### ▶️ 视频回放
- **用途**：播放录制的视频片段
- **功能**：
  - HLS 视频播放器
  - 进度条上的运动点标记
  - 带时间戳的片段列表
  - 点击标记即可跳转到运动事件

## 🎯 第一步

### 步骤 1：查看实时视频流
1. 点击导航栏中的 **“实时监控”** 按钮
2. 确认视频画面正常
3. 查看状态指示（绿色 = 已连接）

### 步骤 2：浏览录像
1. 点击 **“历史记录”** 按钮
2. 查找带有红色的日期（表示有运动活动）
3. 点击有活动的日期

### 步骤 3：播放带运动标记的视频
1. 在回放视图中，从列表里选择一个视频片段
2. 留意进度条上的红色标记
3. 点击任意红色标记即可跳转到该运动事件

## 🔧 故障排除

### 常见问题

**❌ 无法访问 Web 界面**
- 检查设备 IP 地址
- 确保设备已通电
- 确认网络连接正常

**❌ 实时视频流无法工作**
- 检查摄像头连接
- 确认设备正在录制
- 尝试刷新页面

**❌ 视频上没有运动标记**
- 确保视频中有运动事件
- 检查浏览器控制台中的错误
- 确认 API 端点工作正常

**❌ 日历无法加载**
- 检查运动计数 API
- 确认日期格式
- 清除浏览器缓存

## 📱 移动端使用

该界面完全响应式，可在移动设备上使用：

- **触控友好**：按钮和触控区域较大
- **响应式布局**：适配屏幕尺寸
- **移动端优化**：适用于手机和平板

### 移动端技巧
- 使用横屏方向以获得更好的观看体验
- 轻触运动标记即可跳转到事件
- 滑动日历以切换月份

## 🎨 自定义

### 语言切换
点击语言按钮即可在英文和中文之间切换。

### 视频播放器控制
- **播放/暂停**：空格键或点击
- **跳转**：点击进度条或运动标记
- **全屏**：双击视频或使用按钮

### 日历导航
- **上个月**：点击左箭头
- **下个月**：点击右箭头
- **今天**：点击今天的日期

## 📊 理解数据

### 运动计数
- **低（0-50）**：浅绿色
- **中（51-150）**：橙色
- **高（151+）**：红色

### 视频片段
- **文件夹**：片段标识符（00000、00001 等）
- **开始时间**：录制开始的时间
- **时长**：以秒为单位的持续时间
- **运动点**：运动事件的数量

### 运动标记
- **红线**：运动检测事件
- **位置**：基于帧号和视频时长
- **可点击**：直接跳转到运动事件
