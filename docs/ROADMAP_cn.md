## 2.0 里程碑

2.0 不提供从 1.x 迁移的能力：升级需要重刷镜像并清空整张 SD 卡，卡上的录像和配置不保留。

2.0 面向 Luckfox Pico Pro Max。Pico Ultra 排在[它之后](#luckfox-pico-ultra)。

- [x] 板级文件和用户配置都用 JSON（取代 `config.yaml`）

### 网络按钮：临时方案

2026-11-27 讨论的结果。一点都没有实现，以后可能会变。

- 按一下网络按钮，开一个 Wi-Fi 热点，持续十分钟。时间到了并且没有人连着，就关掉。
- 通过它只能访问摄像头：板子只分配地址，不给网关和 DNS 服务器，也不做转发，和 USB 网络上的做法一样。家里没有路由器密码的人可以自己看监控，别的什么都碰不到。
- 密码是每台设备一个默认值，印在标签上，和路由器的做法一样。
- OLED 上显示一个用来加入热点的二维码，旁边是热点的名字。在 0.96 寸的 SSD1306 上用一部手机试过：29×29 格、每格 2 个像素、四周留 3 个像素，内容是 16 个字符的名字加一个密码，这样的码能扫出来。
- 网口保持作 DHCP 客户端。网线直连电脑的需要由 USB 网络满足。
- 通过同一个热点配置家里的 Wi-Fi，想要，但先搁置。
- 它要等 Wi-Fi 卡。这张卡的驱动能不能开热点还没有查过，镜像里也没有开热点的程序。
