## 2.0 里程碑

2.0 不提供从 1.x 迁移的能力：升级需要重刷镜像并清空整张 SD 卡，卡上的录像和配置不保留。

### 板子
- [x] 镜像中带一个只读的板级文件，声明这块板子有什么（取代型号检测）
- [ ] 模块按板级文件和用户配置决定是否启动
- [x] 板级文件和用户配置都用 JSON（取代 `config.yaml`）
- [x] 存储位置来自板级文件（取代写死的挂载点）
- [x] 录制前检查存储已挂载，不会写进 flash
- [ ] Luckfox Pico Ultra 板级配置

### 进程
- [x] 进程退出后自动重新启动
- [x] 看门狗，只由录制进程来喂

### 升级
- [ ] 带 `misc`、`recovery` 和能放下升级包的 `userdata` 的分区表，在 2.0 发布前定下来：以后再改就要再重刷一次。见 [BUILD_cn.md](BUILD_cn.md#分区) 的*分区*一节
- [ ] 通过 recovery 升级：上传的升级包在重启后刷入，中途掉电的刷写会从头再来

### 前端
- [ ] 重新设计前端，使用 Vue + Vite
- [ ] 功能与现有页面持平
- [ ] 日志页面，同时显示安全模式和失败启动计数
- [ ] agent 的路径遵循 [API_cn.md](API_cn.md)

### 录制
- [ ] 优化运动/静止切换逻辑，使运动更连贯

### 开发
- [x] PC 模拟器，前端开发不需要板子
- [x] 全栈开发环境（devcontainer 中加入 Node.js）
- [x] 模拟器不再依赖板子上的固定目录
- [ ] CI 并行发布两个板子
